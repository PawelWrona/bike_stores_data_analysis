# SQL and Power BI Data Analysis on BikeStores Database

## Data Sources
* The data for this project comes from https://www.sqlservertutorial.net/.
* Database link: https://www.sqlservertutorial.net/getting-started/sql-server-sample-database/

## Overview

This Data Analyst project provides the following analyses:
* Changes Over Time Analysis
* Cumulative Analysis
* Part-To-Whole Analysis
* Performance Analysis
  
And reports:
* Store report
* Staff report
* Product report
* Category report
* Customer report
